# Codex 与 Antigravity 作为独立 CLI 提供商并受能力/许可门控

首版目标包含 Codex CLI 和 Antigravity CLI 两种提供商；每种提供商独立检测、列出模型、执行任务并收集输出。模型可用性与具体任务能力分别建模，不能因为模型能聊天或接收图片就认定能生成图片。每次只有获得真实可解码图像时才报告生图成功。

Codex 已有一次端到端测试证明图片文件可取回并被本地网页读取。Antigravity目前仅证明 `gemini-3.8-flash-high` 配合 `image-generator` 子代理能在CLI托管目录生成JPEG；CLI父任务的等待消息/退出码不包含最终图像，因此适配器必须关联父/子会话、等待完成、定位并验证文件。

Antigravity第三方应用包装具有官方计划/条款限制。官方FAQ称第三方软件/工具访问Antigravity可能违反条款，消费者计划不支持在第三方应用中包装`agy`。因此具体适配器只有在该用户的账号计划和调用方式被确认允许后才可启用；不得用账号轮换或其他绕行方式规避限制。未确认前，保留Codex正常可用，Antigravity显示为需资格确认/不可用。
