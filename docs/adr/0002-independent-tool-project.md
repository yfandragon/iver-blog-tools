# 创作工具独立项目维护，IverBlog作为首个目标仓库

创作工具面向各使用者自己的仓库，并计划从文章准备扩展到作品、首页场景等功能，因此独立成一个项目维护；IverBlog作为首个目标仓库，博客中保留工具入口与使用说明，操作页面和执行服务由使用者各自本地启动。相较放在博客仓库内的工具目录，接受额外项目的维护成本，换取工具版本、分发和扩展与个人博客内容分别演进；当前无需把工具操作前端同步部署进博客。

作者已接受这一项目划分，并确认首版先完成文章流程，兼容IverBlog的Astro + Markdown约定；作品和首页场景为后续功能，工具结构从开始保留分类与扩展位置。工具源码目录现确定为`iverBlogTools`，展示名暂定IverBlog Tools（作者工作台）；后续功能细节继续按规格细化。本ADR记录设计决定，不代表已经创建Git仓库、迁移代码、安装依赖或公开源码。

“独立项目”仅指工具自身代码的维护边界。工具执行后改动的是当前目标博客中的相关代码、Markdown、图片与配置；预览确认后push该博客仓库，沿用其已有Cloudflare部署。作品不默认另建仓库或站点。

作者明确确认工具有独立代码仓库，工具自身commit/push或版本发布不影响博客的Cloudflare部署。生成、修改博客本地文件和预览不自动push；只有作者确认后对目标博客配置发布分支的push进入既有部署链路。
